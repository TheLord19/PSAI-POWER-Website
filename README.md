# PSAI POWER - Powering the Future

**Engineering Excellence for a Modern Grid**

PSAI POWER is a premier power engineering firm dedicated to ensuring grid reliability, modernization, and seamless renewable energy integration across Canada and North America.

This platform serves as the digital gateway for our clients in the utility, industrial, and renewable sectors, demonstrating our commitment to cutting-edge technology and engineering precision.

---

## ⚡ Core Solutions

Our application showcases a comprehensive suite of power system services:

*   **Power System Design**: End-to-end design services from feasibility studies to final implementation and testing.
*   **Grid Modernization**: Advanced solutions to modernize and optimize existing power infrastructure for the smart grid era.
*   **Renewable Integration**: Seamless integration of solar, wind, hydro, and battery storage systems.
*   **Maintenance & Optimization**: Preventive and corrective maintenance strategies to maximize asset lifecycle.

## 🛠️ Technology Stack

Built with a focus on performance, SEO, and user experience:

*   **Core**: [Next.js 15](https://nextjs.org/) (App Router) & [React 18](https://react.dev/)
*   **Language**: [TypeScript](https://www.typescriptlang.org/) for robust type safety
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/) for a utility-first design system
*   **Animation**: [Framer Motion](https://www.framer.com/motion/) for fluid, professional transitions
*   **Globalization**: [i18next](https://www.i18next.com/) providing full English and French support
*   **Quality Assurance**: [Vitest](https://vitest.dev/) for unit and integration testing

## 🚀 Getting Started

To run this project locally for development or demonstration purposes:

### 1. Clone the Repository
```bash
git clone https://github.com/TheLord19/PSAI-POWER-Website.git
cd psaipower-website
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 4. Run Tests
```bash
npm test
```
